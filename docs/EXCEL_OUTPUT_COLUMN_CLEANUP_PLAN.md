# Excel 출력 시트 컬럼 정리 기획안

> 사용자 요청 (2026-05-22)
>
> 1. 매입/매출 출력 시트에서 다음 컬럼 제거:
>    - **일자** (매입)
>    - **담당자** (매출/매입)
>    - **세금계산서** (매출 '세금계산서 작성일자')
> 2. 이전 PR #122 에서 UI/인터페이스에서 사라진 항목들도 Excel 출력에 잔존하지 않는지 검증
>
> **수수료 처리**: 사용자 결정 — 새 API 전환 보류, 기존 Motiv API 유지

### 2-1. `SALES_HEADERS` (매출 Excel)

**Before**
```ts
['해당월', '담당자', '세금계산서 작성일자', '거래처명 (사업자등록증 기준)', '광고주명',
 '캠페인명', '공급가액', '세액', '합계금액',
 '수수료 (VAT포함)', '수수료 세금계산서 발행여부',
 'CT ...', 'IMC ...', 'TV ...',
 '비고', '참고', '업데이트', '수금 여부', '실 수금일']
```

**After** (제거: `'담당자'`, `'세금계산서 작성일자'`)
```ts
['해당월', '거래처명 (사업자등록증 기준)', '광고주명',
 '캠페인명', '공급가액', '세액', '합계금액',
 '수수료 (VAT포함)', '수수료 세금계산서 발행여부',
 'CT ...', 'IMC ...', 'TV ...',
 '비고', '참고', '업데이트', '수금 여부', '실 수금일']
```

**보존 사유**: `'수수료 세금계산서 발행여부'` — '세금계산서 자체'가 아닌 '발행 여부 라벨'. 사용자 명시 제거 대상은 "세금계산서 작성일자" 한 항목으로 해석.

**raw sheet (json_to_sheet)**: `담당자`, `'세금계산서 작성일자'` 키 제거.

## 4. 회귀 위험

| ID | 위험 | 영향도 | 완화 |
|---|---|---|---|
| R-01 | 청구서 양식이 외부 거래처에 전달되는데 '담당자' / '일자' 누락이 운영상 문제될 수 있음 | Medium | 사용자 명시 요청. 운영 영향 사용자 책임. |
| R-02 | merge / setColumnWidths 배열 길이 정합성 | High | 컬럼 제거 시 정확히 같은 수만큼 cellRefs/widths 조정. 빌드 후 Excel 다운로드 수동 검증. |
| R-03 | `SalesRow` / `PurchaseRow` 인터페이스에서 `담당자`, `'세금계산서 작성일자'`, `일자` 필드는 **그대로 유지** (override 데이터/UI 입력 가능) — 단지 Excel 출력 시트에서만 제외 | Low | 의도된 분리 — UI 와 Excel 시트가 독립 |
